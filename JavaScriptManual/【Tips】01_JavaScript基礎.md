# JavaScriptの特徴
* スクリプト言語
* 主に、ブラウザ側で動作
* 開発環境の管理、サーバ側のプログラミング、デスクトップアプリケーションの開発にも利用

## Javaとの比較
* 名前似てる理由は、、、マーケティング戦略だった！
* JavaScript は1995年に **Netscape 社**が開発
* 当初の名前は LiveScript だったんですが、Java が当時すごく流行ってた
* そこで「Java って名前つけたら人気出るんじゃね？」と考えて、JavaScript に改名された

| 項目 | Java | JavaScript |
| --- | --- | --- |
| 目的 | サーバーサイド、アプリ開発 | クライアントサイド、Web開発 |
| 実行環境 | JVM (Java Virtual Machine) | ブラウザ or Node.js |
| 型付け | 静的型付け (変数の型を明示) | 動的型付け (実行時に型が決まる) |
| 書き方 | クラスベース | プロトタイプベース |
| 主な用途 | Androidアプリ、業務システム | Webページの動的操作、API連携 |
| コンパイル | コンパイルが必要 | インタプリタで即時実行 |
| 並行処理 | スレッドを使う | 非同期処理 (イベントループ) |
| シンタックス | C言語風だが厳密 | C言語風だが柔軟 |

**【実際の使い分け】**
| 目的 | 使う言語 |
| --- | --- |
| Androidアプリ開発 | Java |
| 業務システムのバックエンド | Java |
| ブラウザの動的な動き追加 | JavaScript |
| WebAPIとの通信 (AJAXなど) | JavaScript |
| Node.jsでサーバー開発 | JavaScript |

# 変数型
`const`, `let`, 'var'との3種類があるが、今は`var`を使わなくなってきてるので古いコードのイメージ  
**※ 基本的には`const` > `let`を優先的に利用することを推奨**  

* `const`：変更不可の変数を定義
  * 初期化必須
  * 再代入不可（再代入しようとするとエラー発生する）
  * ただし、オブジェクトや配列はプロパティの変更は可能
  * **基本は`const`を使う**
* `let`：再代入可能な変数を定義
  * 初期化不要
  * **ブロックスコープ**（関数やif文、ループ内でのスコープ）
  * 巻き上げされるが、初期化されない（宣言前に使うとエラー）
  * **値を更新する可能性がある時だけ使う**
* `var`：古い方法での変数宣言、避けるべき
  * **関数スコープ**
  * 巻き上げされ、初期化される
  * 再代入可能
  * 避けるべき理由：
    * **巻き上げ問題**：宣言がコードの先頭に移動されるので、思わぬバグに繋がる
    * **スコープが緩い**：ブロック外でもアクセス可能

```JavaScript
// 巻き上げ問題
// var の場合
console.log(a); // ✅ undefined (宣言だけ先にされる)
var a = 10;
console.log(a); // 10

// 実際の挙動
var a;          // 宣言が巻き上げられる
console.log(a); // undefined
a = 10;         // 初期化は元の場所で行われる
console.log(a); // 10
/*
宣言だけ先にされるから、エラーにはならずundefinedになる
初期化 (代入) は元の位置で行われる
これがバグの温床になることが多い
*/

// let と const の場合 (ブロックスコープ + 初期化されない)
console.log(b); // ❌ ReferenceError
let b = 20;
console.log(b);

// 実際の挙動
// 宣言は巻き上げられるが、初期化されていない
let b;
console.log(b); // ❌ エラー
b = 20;
console.log(b);
/*
let と const は宣言自体は巻き上げられるが、初期化されない
その結果、宣言前にアクセスするとエラーが発生する ⇒ **バグに気付きやすい**
"Temporal Dead Zone (TDZ)" という期間があって、宣言から初期化されるまでの間はアクセスできない
*/
```

| 宣言方法 | 再代入 | 巻き上げ (hoisting) | スコープ | 基本の使い方 |
| --- | --- | --- | --- | --- |
| `const` | ❌ 不可 | ✅ されるが初期化されない | ブロック | 変更しない変数を使うとき |
| `let` | ✅ 可能 | ✅ されるが初期化されない | ブロック | 変更する可能性がある変数 |
| `var` | ✅ 可能 | ✅ 初期化される | 関数 | 基本的に使わない |

**【スコープについて】**
| スコープの種類 | 説明 | 適用される宣言方法 |
| --- | --- | --- |
| グローバルスコープ | プログラム全体で有効 | `var` `let` `const` |
| 関数スコープ | 関数の中でのみ有効 | `var` |
| ブロックスコープ | {}(ブロック) 内でのみ有効 | `let` `const` |

```JavaScript
const num1 = "10";
const num2 = "30";
console.log(num1 + num2);　⇒　1030　との文字列結果。本当にこのように出力したい場合、テンプレートリテラルの利用を推奨する
console.log(Number(num1) + Number(num2));　⇒　40　との数字計算結果。parseInt()も可
```

# 変数名の制限
* 言語で定められた予約語（constなど）は使用不可
* 変数名の**1文字目は数字以外**
* 利用できる文字
  * 英数字
  * _アンダースコア、$ドル記号
* 付け方の慣習
  * 1文字目
    * **アルファベット**
    * **アンダーバー**
  * 2文字目以降
    * アルファベット
    * アンダーバー
    * 数字
  * 慣習
    * 日本語（全角）で書かない
    * **先頭を小文字**にする
    * 予約語は使えない
    * 複数の単語を組み合わせる場合、**2番目以降の単語の先頭を大文字**にする

# 関数の作り方
```JavaScript
// 指定の仕方は三種類あり
// 1. アロー関数 （一番よく使われる現代的な方法）
const add1 = (a, b) => {
  return a + b;
};
console.log(add1(1, 2)); // 3

// 2. 関数式 （無名関数を変数に代入する方法）
const add2 = function(a, b) {
  return a + b;
};
console.log(add2(1, 2)); // 3

// 3. 関数宣言 （昔ながらの方法、巻き上げがある）
function add3(a, b) {
  return a + b;
}
console.log(add3(1, 2)); // 3
```
※ JavaScriptでは戻り値の型を指定する必要がない (void など不要)  
※ returnは必須ではない  
※ **アロー関数**が今の主流。関数式や関数宣言は状況に応じて使い分ける(関数宣言は巻き上げがあるため)

## コールバック関数
* コールバック関数は、関数に渡される関数のこと
* そのコールバック関数を受け取った関数は、その実行のどこかで受け取ったコールバック関数を実行することが期待される
```JavaScript
// 基本の書き方
function greet(name, callback) {
  console.log("こんにちは、" + name + "さん！");
  callback(); // 渡された関数を実行する
}

function sayGoodbye() {
  console.log("さようなら！");
}

greet("田中", sayGoodbye);
// 出力：
// こんにちは、田中さん！
// さようなら！

// アロー関数を使った例
greet("山田", () => {
  console.log("またね！");
});
// 出力：
// こんにちは、山田さん！
// またね！
```

**【コールバック関数例、非同期処理（API通信やタイマー処理）】**
```JavaScript
console.log("処理開始");

setTimeout(() => {
  console.log("3秒後の処理");
}, 3000);

console.log("処理終了");
// setTimeout は非同期関数なので、3秒待つ間に次の処理が進む
// コールバック関数が3秒後に実行される仕組み
```

**【コールバック関数例、Express.jsを使ったルーティングのコード】**
```JavaScript
// サーバーが特定のURLへのリクエストを受け取った時に実行する処理を定義しているコード
router.get("/", (req, res) => {
  res.send("index");
});
```
* これもコールバック関数であり、router.get は "/" へのアクセスがあったときに、引数として受け取った関数を実行している
* これによって、"/" にアクセスがあった場合に　res.send("index") をする、という処理を実現している

# ランダム数字を作成
Math.random();  
* 小数点以下の数字をランダムに作成

Math.floor(Math.random * 10) + 1; などの書き方も可  
parseInt(Math.random() * 10) + 1;　1から10までのランダム結果を取得  

**【小数点以下の処理について】**
| 関数 | 説明 | 例 | 結果 |
| --- | --- | --- | --- |
| `Math.floor()` | 小さい方に切り捨て | Math.floor(4.9)<br>Math.floor(-4.1) | 4<br>-5 |
| `Math.round()` | 四捨五入 | Math.round(4.5)<br>Math.round(-4.5) | 5<br>-4 |
| `parseInt` | 小数点以下切り捨て | parseInt(4.5)<br>parseInt(-4.5) | 4<br>-4 |
